Methodology

  • Cumulative Method: OptionsSuite compounds official daily TWR geometrically from daily return observations.
  • Privacy: Private brokerage state and identifiers are excluded from the public dataset.
  • Return Source: Official daily time-weighted returns sourced from Interactive Brokers; historical bootstrap uses PortfolioAnalyst and unattended updates use the validated Flex Web Service TWR query.
  • Risk Statistics: Risk statistics are OptionsSuite-derived from the daily TWR series; Sharpe/Sortino currently use a 0% risk-free convention.
  • Selected-window convention: Trailing and calendar-window TWR is rebased to 0% at the start of the selected window; risk statistics are recalculated from daily returns inside that same window.
  • Chart sign convention: Performance curves are green above 0% / 0 pts and red below 0% / 0 pts; drawdown keeps its dedicated neutral curve color.
